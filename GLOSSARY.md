# Telegram Research

The language used for Telegram authentication and reading chat messages.

## Language

**QR login**:
Telegram authentication confirmed on an already authenticated device by scanning a QR code, with the account's cloud password when required.

**Pending login**:
A QR login associated with an authorisation request whose outcome has not yet been delivered.

**Message page**:
A bounded selection of regular messages from one chat's history, search results or reply thread. Scheduled messages are a separate selection.

**Message continuation**:
Reading the next message page with the same chat, filters and thread as the preceding page.
